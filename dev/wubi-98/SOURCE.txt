wubi-98-source.tsv contains all 11,613 single-character entries whose
characters occur in ../gb2312.txt. The original UTF-16 table is converted to
UTF-8, with a char/code header; upstream entry order is preserved. All 6,763
requested characters are covered. No codes are added or inferred.
This subset was extracted on 2026-10-31.

Run: python3 dev/wubi-98/generate_wubi-98.py
The generator can run from any working directory and requires only Python's
standard library. It prefers the shortest listed code per character, keeping
upstream order for ties. It writes characters in ../gb2312.txt order to
wubi-98-code.csv with columns char,key1,key2. key1 is uppercase; key2 is
the second letter, or the repeated first letter for a one-letter short code.
For example, 一=g produces G,g; 明=je produces J,e; 机=sw produces S,w.

This upstream table includes root alternatives under one-letter keys
(for example both 工 and 戈 under a), as well as the usual short-code
characters. These valid alternatives are retained when choosing the shortest
code, rather than replacing them with invented full-code prefixes.
