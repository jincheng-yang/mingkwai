wubi-86-source.tsv contains all 11,012 uncommented single-character entries
whose characters occur in ../gb2312.txt. Only the text and code columns are
retained, in their original upstream order; the YAML header, phrases, weights,
and stem column are omitted. All 6,763 requested characters are covered.
No codes are added or inferred. This subset was extracted on 2026-10-31.

Run: python3 dev/wubi-86/generate_wubi-86.py
The generator can run from any working directory and requires only Python's
standard library. It prefers the shortest listed code per character, keeping
upstream order for ties. It writes characters in ../gb2312.txt order to
wubi-86-code.csv with columns char,key1,key2. key1 is uppercase; key2 is
the second letter, or the repeated first letter for a one-letter short code.
For example, 一=g produces G,g; 明=je produces J,e; 机=sm produces S,m.

This is the Wubi 86 table with its original level 1 and 2 short codes,
as documented by the upstream dictionary's changelog.
